今話題の「ComfyUI」をサクッと導入！
一番簡単なインストール方法

「Stable Diffusion WebUIは使ってるけど、最近よく聞く『ComfyUI（コンフィ・ユーアイ）』って何？」

「画面が線で繋がってて、なんだかプログラミングみたいで難しそう……」

そう思って手を出せていない方、非常にもったいないです！
実はComfyUIは、「動作が圧倒的に軽い（VRAM消費が少ない）」「最新モデル（Fluxなど）がいち早く使える」「インストールが超簡単」という最高の特徴を持っています。

今回は、PythonやGitといったツールの準備すら不要な、一番簡単なインストール方法をガッツリ解説します！

ComfyUIを入れる前の準備

  • OS: Windows 10 または 11
  • グラフィックボード (GPU): NVIDIA製（VRAM 8GB以上推奨ですが、WebUIより少ないVRAMでも動きやすいです！）
  • 解凍ソフト: ダウンロードするファイルが「.7z」という形式なので、7-Zip などの無料解凍ソフトを事前に入れておいてください。
    7-Zip 公式サイト
STEP 1

公式サイトから一式ダウンロードしよう

ComfyUIには、面倒な設定をすべてすっ飛ばせる「全部入りパック（スタンドアロン版）」が用意されています。

  1. 下のボタンから公式ページにアクセスします。
    ComfyUI 公式GitHubページへ
  2. 少し下にスクロールすると、「Installing for Windows」という項目があります。
  3. その中にある Direct link to download というリンクをクリックします。
  4. 容量が約1.5GBほどあるファイルのダウンロードが始まります。完了するまで少し待ちましょう。
STEP 2

好きな場所に解凍（展開）しよう

  1. ダウンロードしたファイル（ComfyUI_windows_portable_nvidia_cuXXX_or_cpu.7z）を右クリックして、「7-Zip」などで解凍します。
  2. 解凍してできた ComfyUI_windows_portable というフォルダを、お好みの場所（CドライブやDドライブの直下など）に移動させます。
  3. 注意！ デスクトップやダウンロードフォルダの中だと、日本語のユーザー名が混ざってエラーになることがあるので、なるべくドライブの直下がおすすめです！

これで……なんとインストール完了です！ 嘘みたいですが本当です。

STEP 3

起動してみよう！

  1. 移動させた ComfyUI_windows_portable フォルダを開きます。
  2. フォルダの中にある run_nvidia_gpu.bat をダブルクリックして実行します。
  3. 黒い画面（コマンドプロンプト）が開き、数秒待つと自動的にブラウザが立ち上がります。
画面に四角い箱（ノード）と線が繋がった初期画面が表示されたら大成功です！
【超重要】WebUIと同じモデルを使いたい！（HDD容量節約の裏技）

WebUIとのモデル共有設定

「すでにWebUIを使っていて、大量のモデル（CheckpointやLoRA）を持っているよ！」という方へ。

そのままComfyUIにもモデルを入れ直すと、HDDやSSDの容量がアッという間に吹き飛びます。

ComfyUIには、「WebUIのフォルダに入っているモデルをそのまま読みに行く」という神機能があります。設定しておきましょう！

  1. ComfyUI_windows_portable フォルダの中の ComfyUI フォルダを開きます。
  2. extra_model_paths.yaml.example というファイルを見つけます。
  3. このファイルの名前を変更し、最後の .example を消して extra_model_paths.yaml にします。
  4. 名前を変えたファイルを、メモ帳などのテキストエディタで開きます。
  5. 上の方に base_path: path/to/stable-diffusion-webui/ と書かれている部分があります。
  6. この path/to/... の部分を、あなたがWebUIをインストールしているフォルダの場所（パス）に書き換えて保存します。
    例： base_path: C:/AI_Projects/stable-diffusion-webui/

これだけで、次回からComfyUIを起動すると、WebUIに入っているモデルやLoRAがそのまま使えるようになります！複数のHDDを使って運用している人には必須の設定ですね。
