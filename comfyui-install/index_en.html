[For super beginners]
Quickly introduce the hot topic “ComfyUI”!
Easiest installation method

"I'm using Stable Diffusion WebUI, but what is 'ComfyUI' that I've heard so much lately?"

"The screens are connected by lines, and it looks like programming, which seems difficult..."

If you think so and haven't gotten around to it, it's such a waste!
Actually, ComfyUI is"It's extremely light in operation (low VRAM consumption)" "You can use the latest models (Flux, etc.) quickly" "It's super easy to install"It has the best characteristics.

This time, we will thoroughly explain the easiest installation method that does not require any preparation of tools such as Python or Git!

Preparations before installing ComfyUI

  • OS: Windows 10 or 11
  • Graphics board (GPU): Made by NVIDIA (VRAM 8GB or more is recommended, but it works easily with less VRAM than WebUI! )
  • Decompression software: Since the file to be downloaded is in the ".7z" format,7-Zip Please install free decompression software such as
    7-Zip official website
STEP 1

Download the set from the official website

ComfyUI has an "all-in-one pack (standalone version)" that allows you to skip all the troublesome settings.

  1. Access the official page from the button below.
    Go to ComfyUI official GitHub page
  2. Scroll down a little and you'll see「Installing for Windows」There is an item called.
  3. in it Direct link to download Click the link.
  4. The download of a file with a capacity of approximately 1.5 GB will begin. Wait a moment for it to complete.
STEP 2

Unzip (unzip) it wherever you like

  1. Downloaded file (ComfyUI_windows_portable_nvidia_cuXXX_or_cpu.7z) and unzip it using something like "7-Zip".
  2. Made by defrosting ComfyUI_windows_portable Move the folder to your preferred location (directly under the C drive or D drive, etc.).
  3. Note! If it is on the desktop or in the download folder, Japanese user names may be mixed up and an error may occur.Directly below the drive if possibleis recommended!

Now...the installation is complete! It sounds like a lie, but it's true.

STEP 3

Let's start it!

  1. moved ComfyUI_windows_portable Open the folder.
  2. inside the folder run_nvidia_gpu.bat Double-click to run it.
  3. A black screen (command prompt) will open, and if you wait a few seconds, the browser will automatically start up.
If you see the initial screen with connected square boxes (nodes) and lines, it's a great success!
[Super important] I want to use the same model as WebUI! (Tips for saving HDD space)

Model sharing settings with WebUI

For those who are already using WebUI and have a large number of models (Checkpoint and LoRA)!

If you re-insert the model into ComfyUI, the capacity of your HDD or SSD will be blown up in no time.

ComfyUI has"Read the model in the WebUI folder as is"There is a divine function called. Let's set it!

  1. ComfyUI_windows_portable in the folder ComfyUI Open the folder.
  2. extra_model_paths.yaml.example Find the file called .
  3. Rename this file and add the last .example Erase extra_model_paths.yaml I'll make it.
  4. Open the renamed file in a text editor such as Notepad.
  5. towards the top base_path: path/to/stable-diffusion-webui/ There is a part that says.
  6. this path/to/... Replace with the location (path) of the folder where you installed WebUI and save it.
    example: base_path: C:/AI_Projects/stable-diffusion-webui/

With just this, the next time you start ComfyUI, you will be able to use the models and LoRA in WebUI as is! This is an essential setting for those who use multiple HDDs.
