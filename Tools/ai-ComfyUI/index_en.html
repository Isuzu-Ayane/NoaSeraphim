List of required custom nodes

💻 ComfyUI-Manager

The most essential management node. The most powerful tool that can automatically detect and install missing nodes in your workflow, as well as centrally manage updates and installations of models and custom nodes themselves.

Open GitHub ↗

⚡ ComfyUI-Easy-Use

A convenient all-in-one tool pack that combines nodes that normally require multiple connections into one. As the name suggests, it is an essential node for "easy use" from loading and saving images to simplifying pipelines.

Open GitHub ↗

💥 ComfyUI-Impact-Pack

A very famous comprehensive pack that is essential for generating high-quality images, including high resolution (upscaling), face and hand detail correction (Detailer type), and segmentation (cropping) of specific areas.

Open GitHub ↗

🔥 ComfyUI-Impact-Subpack

A collection of submodules that complement some of the functions of Impact-Pack. It is introduced in conjunction with advanced nodes that require external dependencies or when you want to use more specialized functionality.

Open GitHub ↗

🛠 rgthree-comfy

A collection of nodes that dramatically improves UIUX. It is extremely powerful in organizing complex workflows, such as the "Context" function that bundles multiple nodes, and the switch node that allows you to mute or bypass them all at once.

Open GitHub ↗

🧩 ComfyUI-KJNodes

A group of utilities that compensate for processing that cannot be accessed with basic nodes, such as mask operations, color correction, noise addition, and batch processing. Useful for image compositing and fine-tuning.

Open GitHub ↗

🔗 cg-use-everywhere

A revolutionary node that can wirelessly (broadcast) common data such as models and prompts to other nodes without physically connecting wires. Keeps the screen beautiful, which tends to look like spaghetti.

Open GitHub ↗

🧰 WAS Node Suite

A huge extended node suite for ComfyUI. A standard node that adds hundreds of wide-ranging features such as image resizing, text processing, powerful image filtering, and Python integration.

Open GitHub ↗

🎨 Comfyroll CustomNodes

(CR Nodes) A ​​large pack specializing in design, animation, and logic processing. It is extremely useful for artistic production such as aspect ratio calculation, text list processing, and color palette generation.

Open GitHub ↗

🤖 ControlNet Auxiliary Preprocessors

A collection of nodes for performing the "preprocessor" that is essential when using ControlNet. This covers feature extraction such as Canny, Depth, OpenPose, and Lineart.

Open GitHub ↗

🎞 ComfyUI-AnimateDiff-Evolved

Extension to integrate "AnimateDiff", a function that uses Stable Diffusion to generate smooth animations and videos. You can output high-quality GIFs/videos while controlling parameters in detail.

Open GitHub ↗

🖌 comfyui-inpaint-nodes

A group of nodes that make it easier and more advanced to perform "in-paint" work, which involves redrawing only part of an image. Helps implement seamless image modifications and enhancements (out-painting).

Open GitHub ↗

📝 sdxl_prompt_styler

Just by selecting from a large number of pre-prepared style templates (anime, photo, cinematic, fantasy, etc.), this node automatically adds the best decorative text to SDXL prompts to improve quality.

Open GitHub ↗

🖼 ComfyUI_LayerStyle

A design-specific node that enables Photoshop-like layer blending processing (drop shadows, borders, gradients, blend mode composition, etc.) on ComfyUI.

Open GitHub ↗

📁 ComfyUI-N-Sidebar

A UI improvement tool that adds a sidebar to the left side of ComfyUI's UI screen that makes it easy to search and add nodes by drag and drop. Node accessibility is dramatically improved.

Open GitHub ↗

🔧 ComfyUI-Custom-Scripts

(pysssss) A collection of function enhancement scripts to make ComfyUI's basic operation system more comfortable and smart, such as AutoComplete (automatic prompt completion), image preview display improvements, node snaps, etc.

Open GitHub ↗

💧 ComfyUI_Fill-Nodes

A support utility node that specializes in filling small areas, such as filling images and masks, expanding and generating masks for in-paint, etc.

Open GitHub ↗

🧠 ComfyUI-IF_AI_tools

An interactive text generation collaboration tool that connects local and API-based LLMs (Ollama, etc.) and calls language models directly within ComfyUI to automatically generate and refine prompts.

Open GitHub ↗

🔎 comfyui-upscale-by-model

A group of dedicated nodes for basic image quality enhancement purposes that use various upscaling models (ESRGAN, OmniSR, etc.) to raise the resolution of generated images to clear and high quality.

Open GitHub ↗

📚 ComfyUI-Lora-Manager

A convenient LoRA central management tool that organizes information on LoRA models, which tend to be huge, with tags and preview images, and allows you to easily select and apply them to prompts on the GUI.

Open GitHub ↗

💾 save-image-extended-comfyui

Extended save node that enhances the default image save function and allows you to customize file naming conventions, change metadata writing settings, save with automatic folder classification, etc.

Open GitHub ↗

🛠 ComfyUI-KikoTools

A group of flexible tools that assist with image processing tasks and data control within workflows, such as cropping part of an image, calculating resolution, and masking specific elements.

Open GitHub ↗

🔀 ControlFlowUtils

A collection of logical operation nodes that control the flow of workflow processing, like programming control syntax (If and Switch), such as data switching (branching) and node bypass based on conditions.

Open GitHub ↗
