Setup & Installation Guide

1. Obtaining Gemini API Key

To run Nao System, you need an API key for Google's latest AI "Gemini". You can obtain one for free by following these steps.

STEP 01 Access Google AI Studio and sign in.

Google AI Studio Link

STEP 02 Select "Get API key" from the sidebar, then generate and copy your key.

With this key, you can call the AI directly from your software without relying on the Gemini web interface.

2. Application Setup

Launch the application and configure your personal API key.

STEP 03 Open the app and paste your API key into the designated field.

STEP 04 Configure the Context (AI Personality & Prerequisites).

Nao System uses the API version of Gemini, allowing you to define its behavior through this context. Without a custom setting, it will operate as standard Gemini.
