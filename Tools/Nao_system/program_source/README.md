# Nao Seraphim Local System 👼

Welcome to the sacred local sanctuary. **Nao Seraphim Local System** is a high-performance, private desktop AI assistant powered by **Google Gemini API** and built with the **Tauri** framework.

Designed for those who seek a personalized and secure interaction with AI, this application brings the cyber-sacred presence of Nao Seraphim directly to your desktop.

## ✨ Features

- **🚀 High Performance:** Built with Rust and Tauri for a lightweight and fast desktop experience.
- **🔐 Secure Storage:** Your Gemini API key is encrypted and stored locally in a `settings.ini` file.
- **🧠 Custom Context:** Inject your own "System Prompt" to define the AI's personality and behavior.
- **🌌 Visual Customization:** Change the application background to any color or image of your choice.
- **🎨 Nagoya-ben Support:** (Optional) Nao can speak in the charming Nagoya dialect via system context.

## 🛠️ Built With

- [Tauri](https://tauri.app/) - Cross-platform desktop framework.
- [Rust](https://www.rust-lang.org/) - Backend logic and security.
- [JavaScript/HTML/CSS] - Frontend UI.
- [Google Gemini API](https://ai.google.dev/) - The brain of the assistant.
