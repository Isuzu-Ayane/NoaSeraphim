【完全無料】画像生成AI
Stable Diffusion WebUI
初心者向けインストールガイド

自分のPCで魔法のように画像を生成。環境構築のすべてを丁寧に解説します。

必要なスペック（推奨）

  • OS: Windows 10 / 11
  • GPU: NVIDIA GeForce RTX シリーズ (必須)
  • VRAM: 8GB以上 (12GB以上推奨)
  • SSD: 50GB 以上の空き容量
STEP 1

Python のインストール

AIを動かすための土台となる言語を準備します。

重要：必ず 3.10.6 というバージョンを使用してください。最新版では動作しない場合があります。
Python 3.10.6 公式サイト
設定のポイント インストール開始時に 「Add Python 3.10 to PATH」 に必ずチェックを入れてください。
STEP 2

Git のインストール

最新のAIプログラムを取得・更新するためのツールです。

Git for Windows 公式

インストーラーの各設定は、すべてデフォルト（Next連打）で問題ありません。

STEP 3

WebUI 本体のダウンロード

コマンド1つで最新のシステムを導入します。フォルダを作成し、アドレスバーに `cmd` と入力して実行してください。

コマンドをコピー
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
STEP 4

自動構築と起動

ダウンロードしたフォルダ内の `webui-user.bat` を実行します。

初回起動時は大量のデータダウンロードが必要です。環境によりますが15分〜30分程度お待ち下さい。

黒い画面に Running on local URL: http://127.0.0.1:7860 と出れば成功です！

🎉 構築完了！

お疲れ様でした！これであなただけのAI画像生成環境が整いました。
