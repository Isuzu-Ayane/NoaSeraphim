Stable Diffusion WebUI
Beginner's Install Guide

Generate magic-like images on your own PC. A comprehensive walkthrough for setting up your local environment.

Requirements (Recommended)

  • OS: Windows 10 / 11
  • GPU: NVIDIA GeForce RTX Series (Required)
  • VRAM: 8GB+ (12GB+ recommended)
  • SSD: 50GB+ free space
STEP 1

Install Python

Prepare the foundation for running the AI.

Important: You MUST use version 3.10.6. Newer versions may cause errors.
Python 3.10.6 Official Site
Crucial Step When the installer starts, make sure to check "Add Python 3.10 to PATH".
STEP 2

Install Git

A tool to download and update the latest AI software.

Official Git for Windows

Keep all installer options as default (click Next until finished).

STEP 3

Download Stable Diffusion

Deploy the entire system with a single command. Create a folder, type `cmd` in the address bar, and run the following:

Copy command
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
STEP 4

First Time Startup

Run `webui-user.bat` inside the downloaded folder.

The first launch will download several GBs of data. Depending on your connection, this may take 15-30 minutes.

The setup is successful when you see Running on local URL: http://127.0.0.1:7860 in the window.

🎉 Setup Complete!

Congratulations! Your personal AI image generation environment is ready.

From here, you can add "Checkpoints" for different art styles or "LoRA" for specific characters to create your ideal artwork.
