誰でも簡単！ローカルLLMを自分のPCで動かす
方法（LM Studio編）

「自分のPCでAIとチャットしてみたいけど、プログラミングや黒い画面（コマンドプロンプト）の操作が難しそう…」

そんな風に思っていませんか？実は「LM Studio」という無料ツールを使えば、ソフトを1つ入れるだけで驚くほど簡単にローカルLLM（自分のPC内で完結するAI）を導入できるんです。

今回は、ダウンロードからAIとのおしゃべり、そして「動作を軽くする裏技」まで、ステップバイステップで解説します！

ステップ1

LM Studioをダウンロードしよう

  1. まずは公式サイト（https://lmstudio.ai/）にアクセスします。
  2. 画面の真ん中にある「Download LM Studio for Windows」をクリックして、インストーラーをダウンロードします。（MacやLinuxの方は、対応するボタンから選んでください）
LM Studio 公式サイトへ
ステップ2

インストールする

  1. ダウンロードしたファイル（LM-Studio-*.exe）をダブルクリックして実行します。
  2. 自動でインストールが進み、完了するとLM Studioが立ち上がります。たったこれだけ！面倒な初期設定は一切ありません。
ステップ3

好きなAIモデルを探してダウンロード

LM Studioの中には、アプリ内から直接世界中のAIモデルを探してダウンロードできる便利な機能がついています。

  1. アプリの左メニューから、ホーム画面（虫眼鏡マーク🔍）を開きます。
  2. 検索窓に、気になるモデルの名前を入力して検索します。（最初は軽めのモデルがおすすめです）
  3. 左側に検索結果が出るのでクリックします。
  4. 右側にファイルの一覧が表示されます。ファイル名の末尾に「Q4_K_M」と書かれたものを選ぶのがポイントです！（これが一番、軽さと賢さのバランスが良い形式です）
  5. 「Download」ボタンを押して、ダウンロードが終わるのを待ちます。
ステップ4

AIとチャットしてみよう！

ダウンロードが終わったら、いよいよAIとおしゃべりです。

  1. 左側のメニューから「吹き出しマーク💬（Chat）」をクリックします。
  2. 画面の一番上にある「Select a model to load」をクリックし、先ほどダウンロードしたモデルを選びます。
  3. モデルが読み込まれたら、一番下の入力欄に「こんにちは！」とメッセージを入れて送信してみてください。

これで、あなた専用のローカルAI環境の完成です！

必見！グラボ（GPU）を使って爆速にする設定

もしあなたのPCにグラフィックボードが搭載されているなら、右側の設定パネルを少し変えるだけで、生成スピードが劇的に速くなります！

  1. 右側のパネルにある 「GPU Offload」 の数値を上げてみてください。これは「計算の一部をグラボに任せる割合（レイヤー数）」です。
  2. VRAM 8GBのグラボをお使いの場合の目安： オフロードの数値を少しずつ（10〜15など）上げていき、上部に表示される予想メモリ使用量（Estimated Memory Usage）の「GPU」が 7.0GB〜7.5GB くらいに収まるように調整するのが最強のコツです。

合わせて 「Context Length」 を 4096 から 2048 などに少し減らすと、さらにVRAMを節約して高速化できます！
