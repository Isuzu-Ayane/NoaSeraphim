Easy for anyone! Run local LLM on your own PC
Method (LM Studio edition)

"I'd like to chat with an AI on my PC, but programming and operating a black screen (command prompt) seem difficult..."

Don't you think so? actually「LM Studio」Using this free tool, you can surprisingly easily introduce local LLM (AI that can be completed within your own PC) just by installing one piece of software.

This time, we will explain step-by-step everything from downloading to chatting with AI to "tricks to make things easier!"

Step 1

Download LM Studio

  1. First of all, the official website (https://lmstudio.ai/).
  2. Click "Download LM Studio for Windows" in the middle of the screen to download the installer. (For Mac or Linux users, please select from the corresponding button)
LM Go to Studio official website
Step 2

install

  1. Downloaded file (LM-Studio-*.exe) to run it.
  2. The installation will proceed automatically and LM Studio will start up when it is complete. That's all! There are no troublesome initial settings.
Step 3

Find and download your favorite AI model

LM Studio has a convenient feature that allows you to search for and download AI models from all over the world directly from within the app.

  1. Open the home screen (magnifying glass mark 🔍) from the left menu of the app.
  2. Search by entering the name of the model you are interested in in the search window. (We recommend a lighter model to start with)
  3. Click on the search results that will appear on the left.
  4. A list of files will be displayed on the right. at the end of the file name「Q4_K_M」The key is to choose the one with this written on it! (This is the format with the best balance of lightness and cleverness.)
  5. Press the "Download" button and wait for the download to finish.
Step 4

Let's chat with AI!

Once the download is complete, it's time to chat with the AI.

  1. Click the "speech bubble mark 💬 (Chat)" from the menu on the left.
  2. Click "Select a model to load" at the top of the screen and select the model you downloaded earlier.
  3. Once the model is loaded, please enter a message saying "Hello!" in the input field at the bottom and send it.

Your own local AI environment is now complete!

Must see! Settings to make it extremely fast using graphics card (GPU)

If your PC is equipped with a graphics board, just a few changes to the settings panel on the right will dramatically speed up the generation!

  1. in the right panel 「GPU Offload」 Try increasing the value. This is the "ratio (number of layers) of leaving part of the calculation to Grabo."
  2. If you are using a graphics card with 8GB of VRAM: Increase the offload value little by little (10 to 15, etc.) until the "GPU" of the Estimated Memory Usage displayed at the top is 7.0GB〜7.5GB The best trick is to adjust it so that it fits within this range.
