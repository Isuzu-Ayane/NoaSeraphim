Things to prepare (required specs)

To run Stable Diffusion smoothly, you need a little bit of PC power.

  • OS: Windows 10 or 11
  • Graphics board (GPU): NVIDIA (GeForce RTX 3060, 4060, etc.) is required!
  • VRAM (grabo memory): 8GB or more recommended (12GB is best)
  • Storage: to SSD 50GB That's allFree space (because it increases as you add more models)
STEP 1

Let's install Python

It is a programming language that is the foundation for running AI.

Note: Be sure to「3.10.6」Please enter the version.
If you use the latest version, you will get an error!
  1. Access the official page from the button below, and click at the bottom. Windows installer (64-bit) Download.
    Go to Python 3.10.6 official page
  2. Open the downloaded file.
  3. [This is the most important part! ] at the bottom of the installation screen 「Add Python 3.10 to PATH」 In the checkbox calledBe sure to checkplease.
  4. Click "Install Now" to complete.
STEP 2

Let's install Git

This is a tool for downloading the complete Stable Diffusion system.

  1. Access the official page from the button below, 64-bit Git for Windows Setup Download.
    Go to Git official page
  2. Open the downloaded file.
  3. Many English screens appear, but allHit "Next" repeatedlyIt's OK to do so. Finally, press "Install" and you're done!
STEP 3

Download Stable Diffusion WebUI

It's finally time to download the main unit! It may look difficult, but don't worry, it's just a matter of copying and pasting a magic spell.

  1. Where you want to install it (directly under the C drive, etc.)Create a new folder.(example: AI_Projects etc.)
  2. Open the folder you created and click at the top of the screen.address bar(where the path is displayed) cmd Type and press Enter.
  3. A black screen (command prompt) will open.
  4. Copy and paste the following characters on the black screen (right click) and press Enter.
copy and paste
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git

Wait a few seconds and the download will be completed, and you will find it in the folder. stable-diffusion-webui If you have created a new folder called ``, it's a great success!''

STEP 4

Finally launched!

Now, you're ready. Let's wake up the AI!

  1. Just finished it stable-diffusion-webui Open the folder.
  2. It's at the bottom webui-user.bat Double-click the file. (*Depending on settings) .bat can't see webui-user is displayed)
  3. A black screen will appear and downloading of the necessary data will begin automatically.
The first time, several GB of data will be dropped, so it will take about 10 to 30 minutes depending on your line. Grab some coffee and wait patiently!

to a black screen Running on local URL: http://127.0.0.1:7860 When it is displayed, it is a signal that preparation is complete!

STEP 5

Open it in your browser and create an image!

  1. Open your favorite browser (Chrome, Edge, etc.).
  2. in the address bar http://127.0.0.1:7860 Type and press Enter.
  3. The Stable Diffusion operation screen opens!
  4. Enter what you want to create in English in the input field labeled "Prompt" in the upper left.
    5. example: 1girl, cute, smile, blue hair, outdoors
  5. orange on the right "Generate" Click the button!
Wait a few seconds and you should see the first AI image you created on the right side of the screen!
