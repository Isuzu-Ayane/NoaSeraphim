Stable Diffusionの簡単なローカルインストール方法まとめ

「AIで自分好みのイラストを作ってみたいけど、何から始めればいいか分からない…」

「インストールとか難しそうで諦めた…」

そんなアナタのために、今回は自分のPCで動かす
「Stable Diffusion WebUI（AUTOMATIC1111版）」
のインストール方法を、どこよりも分かりやすくガッツリ全公開しちゃいます！

一度環境を作ってしまえば、あとは完全無料・無制限で画像を作り放題です。
手順通りにやれば絶対にできるので、一緒にやってみましょう！

準備するもの（必須スペック）

Stable Diffusionを快適に動かすには、ちょっとだけPCのパワーが必要です。

  • OS: Windows 10 または 11
  • グラフィックボード (GPU): NVIDIA製（GeForce RTX 3060, 4060など）が必須！
  • VRAM (グラボのメモリ): 8GB以上推奨（12GBあると最高です）
  • ストレージ: SSDに 50GB 以上の空き容量（モデルを入れるとどんどん増えるため）
STEP 1

Python（パイソン）をインストールしよう

AIを動かすための土台となるプログラム言語です。

注意：必ず「3.10.6」というバージョンを入れてください。
最新版だと逆にエラーになります！
  1. 下のボタンから公式ページにアクセスし、一番下にある Windows installer (64-bit) をダウンロードします。
    Python 3.10.6 公式ページへ
  2. ダウンロードしたファイルを開きます。
  3. 【ここが一番重要！】 インストール画面の下にある 「Add Python 3.10 to PATH」 というチェックボックスに必ずチェックを入れてください。
  4. 「Install Now」をクリックして完了です。
STEP 2

Git（ギット）をインストールしよう

Stable Diffusionのシステム一式をダウンロードしてくるためのツールです。

  1. 下のボタンから公式ページにアクセスし、 64-bit Git for Windows Setup をダウンロードします。
    Git 公式ページへ
  2. ダウンロードしたファイルを開きます。
  3. 英語の画面がたくさん出ますが、すべて「Next」を連打してOKです。 最後に「Install」を押して完了！
STEP 3

Stable Diffusion WebUI をダウンロードしよう

いよいよ本体のダウンロードです！難しそうに見えますが、魔法の呪文をコピペするだけなので安心してください。

  1. インストールしたい場所（Cドライブ直下など）に新しくフォルダを作ります。（例： AI_Projects など）
  2. 作ったフォルダを開き、画面上部のアドレスバー（パスが表示されている所）に cmd と入力してEnterキーを押します。
  3. 黒い画面（コマンドプロンプト）が開きます。
  4. 以下の文字をコピーして、黒い画面に貼り付け（右クリック）、Enterを押します。
コピーして貼り付け
git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git

数秒待つとダウンロードが完了し、フォルダの中に stable-diffusion-webui という新しいフォルダができていれば大成功です！

STEP 4

ついに起動！

さぁ、準備は整いました。AIを目覚めさせましょう！

  1. さきほどできた stable-diffusion-webui フォルダを開きます。
  2. 下の方にある webui-user.bat というファイルをダブルクリックします。（※設定によっては .bat が見えず webui-user とだけ表示されています）
  3. 黒い画面が立ち上がり、自動で必要なデータのダウンロードが始まります。
初回は数GBのデータを落とすので、回線によっては10分〜30分くらいかかります。コーヒーでも飲んで気長に待ちましょう！

黒い画面に Running on local URL: http://127.0.0.1:7860 と表示されたら準備完了の合図です！

STEP 5

ブラウザで開いて画像を作ってみよう！

  1. いつも使っているブラウザ（ChromeやEdgeなど）を開きます。
  2. アドレスバーに http://127.0.0.1:7860 と入力してEnterを押します。
  3. Stable Diffusionの操作画面が開きます！
  4. 左上の「Prompt（プロンプト）」という入力欄に、英語で作ってみたいものを入力してみましょう。
    5. 例： 1girl, cute, smile, blue hair, outdoors
  5. 右側のオレンジ色の 「Generate（生成）」 ボタンをポチッ！
数秒待つと……画面の右側に、あなたが初めて生み出したAI画像が表示されるはずです！
🎉 おめでとうございます！ 🎉

おわりに

インストールお疲れ様でした！

最初は英語ばかりで戸惑うかもしれませんが、触っているうちにすぐに慣れますよ。

次回からは、ステップ4の webui-user.bat をダブルクリックするだけでいつでも起動できます。
